# الدلالة — معرض سيارات إلكتروني

دلالة سيارات: صفحة عرض عروض السيارات (static) بلا لوحة تحكم ولا سلة شراء، وتعمل كتطبيق على الجوال (PWA).
الزائر يبحث ويشاهد تفاصيل السيارة ثم يتواصل على واتساب لترتيب المعاينة.

- الموقع/التطبيق المنشور: https://elhassanali36-art.github.io/Al-Dalala/
- تعديل السيارات: `data.js` فقط (الاسم، السعر، العمولة، المواصفات، الصور).
- زر الواتساب: `settings.whatsapp` في `data.js`.

لا يوجد أي دخول إداري أو لوحة تحكم في الواجهة.

## تطبيق الجوال
`manifest.webmanifest` + `sw.js` يجعلان الموقع قابلاً للتثبيت على الشاشة الرئيسية ويفتح بلا شريط المتصفح (PWA). الأيقونات في `img/icon-*.png`.
